# Variant families: API reference

> Generated by `npm run docs:api` from the JSDoc in `src/library/components/*/types.js`. Edit the JSDoc, not this file.

Required props are marked **yes**. Callbacks (props that are functions) are listed separately: the library never
changes your data, it calls these and you update your own state.

## Navbar

Header with brand, links, search and account / wishlist / cart actions.

```jsx
import { Navbar } from 'ecom-ui-kit'
```

Default variant: `minimal`. See "Choosing a variant" in the README for the names and fallback rules.

**Required:** `brand`

## ProductCard

One product. Presentational: your page owns the cart and the wishlist.

```jsx
import { ProductCard } from 'ecom-ui-kit'
```

Default variant: `minimal`. See "Choosing a variant" in the README for the names and fallback rules.

**Required:** `product`

### Props

| Prop | Required | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `variant` |  | `'minimal'\|'sale'\|'overlay'\|'horizontal'\|'luxury'` | `'minimal'` | Design to render. Unknown values fall back to the default and warn in development. |
| `product` | **yes** | `Product` |  |  |
| `isWishlisted` |  | `boolean` | `false` | Controlled. The card keeps no wishlist state of its own. |
| `addingToCart` |  | `boolean` | `false` | Controlled. Shows the busy state on the add-to-cart button. |
| `currency` |  | `string` | `'USD'` | ISO 4217 code used to format prices. |
| `locale` |  | `string` |  | BCP 47 tag for number formatting. Defaults to the browser's. |
| `labels` |  | `ProductCardLabels` |  |  |
| `headingLevel` |  | `2\|3\|4\|5\|6` | `3` | Heading level of the product name. |
| `className` |  | `string` |  |  |

### Callbacks

| Prop | Required | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `onAddToCart` |  | `(product: Product, event: React.MouseEvent) => void` |  | Omit to hide the add-to-cart button. |
| `onToggleWishlist` |  | `(product: Product, event: React.MouseEvent) => void` |  | Omit to hide the wishlist button. |
| `onProductClick` |  | `(product: Product, event: React.MouseEvent) => void` |  | Fires when the card is activated. Call `event.preventDefault()` to route client-side. |
| `formatPrice` |  | `(amount: number, product: Product) => string` |  | Replaces the built-in price formatting. |

## ProductGrid

List of cards; `variant` selects the card design. Forwards card props.

| `variant` |  | `'minimal'\|'sale'\|'overlay'\|'horizontal'\|'luxury'` | `'minimal'` | Design to render. Unknown values fall back to the default and warn in development. |
| `products` | **yes** | `Product[]` |  |  |
| `columns` |  | `1\|2\|3\|4` |  | Columns on wide screens. Defaults to the variant's own responsive layout. |

## Sidebar

Category list and filter groups. Your page owns the category and filter state.

```jsx
import { Sidebar } from 'ecom-ui-kit'
```

Default variant: `classic`. See "Choosing a variant" in the README for the names and fallback rules.

**Required:** none

### Props

| Prop | Required | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `variant` |  | `'classic'\|'collapsible'\|'minimal'` | `'classic'` | Design to render. Unknown values fall back to the default and warn in development. |
| `categories` |  | `Category[]` | `[]` |  |
| `activeCategory` |  | `string\|number\|null` | `null` | Controlled. `null` highlights the "All" row. |
| `filterGroups` |  | `FilterGroup[]` | `[]` |  |
| `filters` |  | `FilterState` | `{}` | Controlled. |
| `labels` |  | `SidebarLabels` |  |  |
| `ariaLabel` |  | `string` |  | Accessible name of the sidebar landmark. Defaults to the "Filters" label. |
| `headingLevel` |  | `2\|3\|4\|5` | `2` | Level of the sidebar title. Sections inside use the next level. |
| `className` |  | `string` |  |  |

### Callbacks

| Prop | Required | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `onCategoryChange` |  | `(id: string\|number\|null, category: Category\|null, event: React.MouseEvent) => void` |  | Called with `null` for the "All" row. Links navigate unless you call `event.preventDefault()`. |
| `onFiltersChange` |  | `(next: FilterState) => void` |  | Receives the complete next filter object. |
| `onClearAll` |  | `() => void` |  | Defaults to `onFiltersChange({})`. Provide it to also reset search, page, etc. |

import { Footer } from 'ecom-ui-kit'

| Prop | Required | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `variant` |  | `'simple'\|'columns'\|'newsletter'\|'dark'` | `'columns'` | Design to render. Unknown values fall back to the default and warn in development. |
| `brand` | **yes** | `FooterBrand` |  |  |
| `columns` |  | `FooterColumn[]` |  | Link groups. Shown by every variant except `simple`. |
| `links` |  | `FooterLink[]` |  | Flat links for `simple`. Falls back to the first 6 links of `columns`. |
